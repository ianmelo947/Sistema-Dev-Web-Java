# 🌱 Alerta Verde

**Sistema de Monitoramento Climático e Gestão Agrícola**

  Projeto acadêmico focado em auxiliar produtores rurais através do monitoramento de dados meteorológicos em tempo real e recomendações inteligentes de irrigação e plantio. 

  O sistema avalia as condições climáticas locais e cruza com uma base de dados de limites térmicos de diversas culturas (como milho, feijão, hortaliças, etc.) para sugerir as melhores práticas de manejo e alertar sobre climas extremos.

##  Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização responsiva e interface moderna (Split Layout).
* **JavaScript (Vanilla JS):** Lógica de negócios, simulação de colheita, cálculos térmicos e consumo de API externa.
* **OpenWeatherMap API:** Integração para busca de dados climáticos e previsão do tempo em tempo real.

##  Como Executar

  Por ser uma aplicação 100% Client-side (Front-end), a execução é imediata e não exige a instalação de dependências, banco de dados ou servidores locais, necessitando talvez somente o uso da extensão Live Server para execução em VScode.

**Observações:**

  Mesmo com o tema recebido sendo tecnologia, por ser muito abrangente, optamos por aprofundar na temática de agricultura voltada para uso funcional de trabalhadores da zona rural devido já a familiaridade com tal tema, mas que pode ser facilmente adaptado para uso urbano, como jardinagem residencial/comercial e usos pessoais como cuidados de plantas domésticas.
